### 4.3 Mask 区域内（核心问题）

| 指标 | 数值 |
|------|------|
| 前景像素 | 5298 |
| 深度 = 0 | **4883（92.2%）** |
| 有效深度 (0, 4m] | **415（7.8%）** |
| 有效深度中位数 | 0.386 m |
| Mask 中心处深度 | **0（无效）** |

Mask 内 raw depth 分布：

| raw 范围 (mm) | 像素占比 |
|---------------|----------|
| 0 | 92.2% |
| 1–500 | 6.8% |
| 801–1200 | 1.1% |
| 501–800 / >1200 | 0% |

GenPose2 `InferDataset` 会将深度 > 4.0 m 置 0；若 `depth_scale` 误用 1.0（未转米），mask 内平均 raw 约 35，仍会被当作有效，但本案例服务已正确使用 0.001。

### 4.4 与 PEM 输出对比

| 来源 | z 方向 (mm) |
|------|-------------|
| PEM 平移 `t[2]` | **513.2** |
| Mask 内有效深度中位数 | **386.0** |
| 差值 | **127.2 mm** |

位姿 z 与 mask 区域实测深度不一致，符合「mask 内有效点极少、点云不代表真实物体」的判断。

## 5. Mask — 格式正常，覆盖区域有问题

### 5.1 格式

- PNG：`unique = [0, 1]`，单实例
- 转 EXR 后与 cutoop 约定一致
- 与 `091721` 请求使用 **完全相同** 的 mask（5298 px，bbox 33×196）

### 5.2 空间形状

| 指标 | 数值 |
|------|------|
| 2D bbox | x: 277–309，y: 94–289 |
| 尺寸 | **33 × 196 px**（极窄竖条） |
| 中心 | (293.5, 198.4) |
| 主点 | (328.3, 248.3) |

`vis_ism.png` 可见：绿色 mask 落在中间线轴上，但是一条 **很窄的竖条**，更像线轴左缘或支架，而非完整线轴盘面。

### 5.3 原因分析

1. **半透明塑料 + 金属架**：深度相机在镂空/反光/半透明区域常返回 0
2. **Mask 过窄**：仅 33 px 宽，落在深度空洞集中的边缘
3. **Mask ∩ 有效深度** 仅 415 px，GenPose2 需采样约 1024 点，数据严重不足

## 7. 建议

1. **扩大 mask**：覆盖整个线轴盘面，避免 33 px 竖条
2. **对齐有效深度**：mask 应主要落在 `(depth > 0) & (depth ≤ 4m)` 区域；目标有效占比 **> 50%**（本案例仅 7.8%）
3. **检查深度源**：调整相机角度、曝光或深度滤波，减少半透明/金属导致的空洞
4. **上线前自检**：对 `(mask > 0) & (depth > 0)` 占比做阈值告警

### 推荐自检指标

```
mask_valid_depth_ratio = (mask内有效深度像素数) / (mask前景像素数)
```

| ratio | 建议 |
|-------|------|
| > 0.5 | 可正常推理 |
| 0.2 ~ 0.5 | 谨慎使用，检查 mask/深度对齐 |
| < 0.2 | 不建议推理，先修正 mask 或深度 |
