|version（可选）<br>|text|软件版本（接入平台工程）<br>"1\.0\.5"||

# 二、HTTP传输方式

机器人通过脚本通过HTTP传输到DMP平台

## 1\.1 获取token 

HTTP设备上报属性和事件需要携带token进行鉴权校验，且暂不提供命令下发场景。HTTP设备可通过以下方式获取token：

验证通过后，token将在响应体Body中给出，有效期为3×24小时，过期之后可再次使用此接口获取有效的token。设备第一次调用该接口时，平台会记录deviceId，之后每一次调用请使用相同的deviceId，否则将无法获取token。

## 1\.2 上报事件和属性

HTTP设备在获取有效的token后，可通过以下地址进行属性和事件的上报。 

上报单个属性可使用如下方法：

```HTTP
POST https://dmp-https.cuiot.cn:8943/topic/sys/{productKey}/{deviceKey}/property/pub
Host: dmp-https.cuiot.cn:8943
Content-Type: application/octet-stream
Authorization: ${token}
Body:${your_data}
${your_data}是将以下内容转成UTF-8编码的字节数组
{
    "messageId":"123",
    "params": {
    "key":"temperature",
    "value": 23.4,
    "ts": "1528292272000"
}

返回结果示例：
{
  "code" : "000000",
  "message":"",
  "messageId":"123",
  "data":[ ]
}
 
{
  "code" :  "000001",
  "message" :"Error",
  "messageId":"123",
   "data":[ ]  
}
```

其余属性批量上报，事件上报，事件批量上报Body的内容同MQTT的对应payload。
