以下是导航点位参数。

task_boundary（任务判定点）start（起点）这俩是任务起点和终点，实际是同一个点；
receipt_viewpoint（小票识别）delivery_place（交付台放货），这俩实际是同一个点；
replenishment_pickup（补货台取货）。

| target_id | 点号 | 说明 |
|---|:---:|---|
| H1_INSPECT | 1号 | 正对货架1 |
| H12_INSPECT | 2号 | 货架1与货架2连接处 |
| H2_INSPECT | 3号 | 正对货架2 |
| H23_INSPECT | 4号 | 货架2与货架3连接处 |
| H3_INSPECT | 5号 | 正对货架3 |

这个是任务一执行放置
curl -X POST http://<robot_ip>:8084/manipulation/release \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: release-left-001' \
  -d '{
    "task_type":"SORTING",
    "product_name":"商品名",
    "hand":"LEFT",
    "pose":[0,0,0,0,0,0],
    "frame":"camera",
    "pose_unit":"mm_rad",
    "rotation_order":"zyx"
  }'

当放置参数是SORTING时，不需要调用其他的模块，place里，跳过其他模块，只需要直接调用manipulation/release，输入左手还是右手，其他参数按上面的样例来。不需要定位等步骤。

任务一到达交付台且左右手都持有商品时，直接同时释放两件商品：

```bash
curl -X POST http://<robot_ip>:8084/manipulation/release/both \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: dual-release-001' \
  -d '{
    "task_type":"SORTING",
    "left":{"product_name":"左手商品名"},
    "right":{"product_name":"右手商品名"}
  }'
```
