target_id是8个导航巡检点，在任务二、三找缺货和换货时会用到。


所有商品编号，如 H1_F_L1_C01 也是导航模块的合法输入，导航模块会在内部转换成对应货架点 ，导航过去。



这个位姿是任务一中放置物品位姿
curl -X POST http://<robot_ip>:8084/pose/prepare \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: place-ready-001' \
  -d '{"pose_type":"DELIVERY_TABLE_PLACE_READY"}'

这个是任务一执行放置
curl -X POST http://<robot_ip>:8084/manipulation/release \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: release-left-001' \
  -d '{
    "task_type":"SORTING",
    "product_name":"商品名",
    "hand":"LEFT",
    "pose":[0,0,0,0,0,0],
    "frame":"camera",
    "pose_unit":"mm_rad",
    "rotation_order":"zyx"
  }'

当放置参数是SORTING时，不需要调用其他的模块，place里，跳过其他模块，只需要直接调用manipulation/release，输入左手还是右手，其他参数按上面的样例来。不需要定位等步骤。

任务一到达交付台且左右手都持有商品时，直接同时释放两件商品：

```bash
curl -X POST http://<robot_ip>:8084/manipulation/release/both \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: dual-release-001' \
  -d '{
    "task_type":"SORTING",
    "left":{"product_name":"左手商品名"},
    "right":{"product_name":"右手商品名"}
  }'
```
