## 公共约定

### 健康检查

健康检查请求体为空。模块状态返回值为：

```text
STARTING  模块正在初始化
READY     模块可以接收任务
ERROR     模块故障
```

Agent 只有在任务依赖的模块全部返回 `READY` 后才开始执行。

### 物理动作

以下接口属于物理动作接口：

```text
POST /navigation/navigate
POST /pose/prepare
POST /manipulation/pick
POST /manipulation/place
```

请求必须携带：

```http
Idempotency-Key: <task_run_id>:<action_id>
```

同一个逻辑动作发生网络重试时，Agent 使用相同请求体和相同 `Idempotency-Key`。服务端收到重复键时必须返回原动作结果，不能再次执行真实动作。

物理动作成功返回 HTTP `200`：

```json
{"status":"SUCCEEDED"}
```

执行失败返回非 `2xx`：

```json
{"error_code":"EXECUTION_FAILED"}
```

导航、位姿、抓取和放置都是长程阻塞调用。接口应在动作真正完成后返回，不能在刚接收请求时提前返回 `SUCCEEDED`。

## 需要确认

当前商品库三个查询接口使用 `GET + JSON 请求体`。部分 HTTP 网关和客户端可能忽略 GET 请求体。如果后续需要经过网关，建议改为查询参数，例如：

```http
GET /sku/locations?name=NFC桔汁
GET /sku/images?name=NFC桔汁
GET /sku/name?location=H1_F_L1_C01
```

本表是目标端口规划。当前项目 [agent.yaml](../config/agent.yaml) 仍使用 Mock 联调端口 `8101-8104`，尚未切换到 `8081-8084`。
